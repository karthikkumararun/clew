# Quality loop

The loop for a release, from a clean machine to a release gate.

1. **Run the suites.** `pnpm qa:up` (needs Docker; `--profiles core,nosql` to choose), then
   `pnpm qa:e2e --suite smoke` and `pnpm qa:e2e --suite full`. `pnpm qa:e2e` rebuilds the app when
   the sources changed. Results and failure artifacts are in `e2e/artifacts/`. `pnpm qa:down`
   stops the stack and removes its volumes.
2. **Run the manual checklist.** `pnpm qa:checklist` writes `docs/qa/checklist.md`. Copy it to
   `docs/qa/runs/<date>-<platform>.md`, record the build commit, tick what passes and link an
   issue to what fails. Do this on macOS and on Windows. Use `charters.md` for exploratory
   passes.
3. **File defects.** Use the Defect issue template. Severity S1 (data loss, security, crash,
   unusable) to S4 (cosmetic). Attach a screenshot and the diagnostics report (About, Copy
   diagnostics: it contains no passwords or hostnames). If the spec was wrong, relabel the issue
   `spec` and fix the spec and design first.
4. **Fix with a regression test.** Branch `fix/<issue>-<slug>`. Test first, at the lowest level
   that can observe the defect. The pull request names the spec scenario, the defect class
   (`defect-classes.md`) and the guard against the class. `fix-prompt.md` is the prompt to hand
   an agent.
5. **Re-run and re-check.** Re-run the suites for the capability. The maintainer re-checks the
   original steps before closing the issue.
6. **Release gate.** `pnpm qa:gate <commit>` checks that no S1 or S2 defect is open, the workflow
   runs are green for the commit, the checklist run files exist for macOS and Windows, and
   `docs/qa/coverage.md` shows no uncovered scenario of a shipped capability.

The gate also reads `docs/qa/design-review.json` (written after the design review:
`{"commit": "<sha>", "states": {"<Screen state>": "approved" | "discrepancies"}, "discrepancies":
[{"issue": 12, "severity": "S4"}]}`); every state must be approved, or have only S4 discrepancies
filed.

Other references: `docs/qa/coverage.md` (generated by `pnpm check:coverage`),
`docs/qa/defect-classes.md`, `docs/qa/charters.md`.
